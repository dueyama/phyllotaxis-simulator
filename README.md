# 葉序問題を学ぶ

フィボナッチ数列、黄金比、黄金角、葉序に現れる左右の螺旋数、Douady-Couder 型の反発最小化モデルを順に学ぶための公開用ウェブ教材です。

## 公開方針

- `paper/` はローカル参照専用で、GitHub/Vercel には公開しません。
- PDF のスクリーンショット、切り抜き、ページ画像は使いません。
- 図、粒子配置、螺旋線、分岐図、シミュレーションはすべてコードで再構成します。

## 開発

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

Vercel では通常の Vite 静的サイトとしてデプロイできます。
